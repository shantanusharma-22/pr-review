# Security Policy

## Supported Versions

We actively maintain and provide security updates for the primary release branches:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

Security is a fundamental pillar of evidence-first code reviews. If you discover a security vulnerability within this repository, prompt definitions, or execution references:

1. **Do not create a public GitHub issue.**
2. Send an email to **shantanusharma848@gmail.com** with details of the vulnerability, reproduction steps, and potential impact.
3. You will receive an acknowledgment within 48 hours.
4. We will coordinate a fix and release an advisory once the resolution is verified.

Thank you for helping keep our tools and workflows safe for everyone!
